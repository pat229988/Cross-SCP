# CrossSCP GUI Resources

Product artwork is stored here for build/runtime use.

The original backup copies provided by the project owner remain under `DOC/assets/`.

## Icons

- `icons/crossscp.ico` - Windows icon resource.
- `icons/crossscp.svg` - scalable source logo for Qt resources.
- `icons/crossscp-256.png` - UI/runtime raster icon.
- `icons/crossscp-512.png` - high-resolution raster icon.
- `icons/crossscp-1024.png` - app-store/high-resolution raster icon.
- `icons/crossscp-full.png` - full logo lockup.
