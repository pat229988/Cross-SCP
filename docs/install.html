Install and trust guide

Install CrossSCP safely on your desktop.

Use these steps for beta releases, post-install checks, platform warnings, and complete Linux cleanup when switching between RPM, DEB, and Flatpak builds.

Before installing: why warnings appear

CrossSCP is open source and the builds are produced by GitHub Actions, but beta packages are not yet distributed through every platform's paid or official trust channel.

macOS Gatekeeper

Browser downloads receive quarantine metadata. Without Apple Developer ID notarization, macOS may block the app. The terminal installer removes quarantine from the installed copy.

Windows SmartScreen

Unsigned Windows installers show Unknown/Unverified Publisher. Removing that warning requires a paid Authenticode code-signing certificate.

Linux package trust

Downloaded DEB/RPM/Flatpak beta artifacts can be verified with checksums, but they are not equivalent to APT, COPR, or Flathub distribution yet.

Verify downloads

shasum -a 256 -c CrossSCP-*.sha256
# Linux alternative:
sha256sum -c CrossSCP-*.sha256

macOS install

Recommended free tester install:

curl -fsSL https://raw.githubusercontent.com/pat229988/Cross-SCP/dev/scripts/install-macos.sh | bash

Manual Gatekeeper fallback

sudo xattr -dr com.apple.quarantine /Applications/CrossSCP.app
open /Applications/CrossSCP.app

Uninstall

rm -rf /Applications/CrossSCP.app
rm -rf "$HOME/Applications/CrossSCP.app"

macOS first-run visual guide

If you install the unsigned beta manually and macOS blocks the first launch, follow these approval steps.

Click Done

When macOS shows Move to Trash / Done, choose Done.

Open Settings

Open macOS System Settings from the Dock or Apple menu.

Privacy & Security

Select Privacy & Security in System Settings.

Open Anyway

Scroll to Security and click Open Anyway for CrossSCP.

Confirm

When prompted again, choose Open Anyway.

Windows install

Download the setup EXE or portable ZIP from GitHub Releases or the latest workflow artifacts.

  1. If SmartScreen appears, click More info.
  2. Confirm the app name is CrossSCP and the download came from the official repository.
  3. Click Run anyway.

The installer bundles Qt and Microsoft Visual C++ runtime DLLs such as Qt6Core.dll, Qt6Gui.dll, Qt6Qml.dll, vcruntime140.dll, and msvcp140.dll.

Uninstall

Use Settings → Apps → Installed apps → CrossSCP → Uninstall, or the Start Menu Uninstall CrossSCP shortcut.

Ubuntu / Debian install

sudo apt install ./CrossSCP-*-ubuntu-amd64.deb

Uninstall

sudo apt remove crossscp
# Deeper cleanup:
bash scripts/uninstall-linux.sh --remove-config

Fedora RPM install

sudo dnf install ./CrossSCP-*-fedora-x86_64.rpm

If DNF warns that the local RPM is unsigned, install only if you trust the GitHub Actions artifact and checksum.

Uninstall

sudo dnf remove crossscp
# Remove stale launchers too:
bash scripts/uninstall-linux.sh
Screenshot placeholder: fedora-kde-stale-launcher.png

Flatpak install

sudo dnf install flatpak
flatpak remote-add --if-not-exists flathub https://flathub.org/repo/flathub.flatpakrepo
flatpak install --user ./CrossSCP-*-linux-x86_64.flatpak
flatpak run org.crossscp.CrossSCP

The Flatpak file can be small because the shared KDE runtime is downloaded separately from Flathub.

Uninstall

flatpak uninstall --user org.crossscp.CrossSCP
# If old RPM/DEB launchers remain:
bash scripts/uninstall-linux.sh

Linux post-install checks

Run from a terminal first. This shows useful errors if the desktop launcher fails.

# Flatpak
flatpak run org.crossscp.CrossSCP

# RPM/DEB
/usr/bin/CrossSCP

Find duplicate or stale launchers

find ~/.local/share/applications /usr/share/applications \
  ~/.local/share/flatpak/exports/share/applications \
  /var/lib/flatpak/exports/share/applications \
  \( -iname '*crossscp*.desktop' -o -iname '*CrossSCP*.desktop' \) 2>/dev/null

Refresh KDE menu cache

kbuildsycoca6 --noincremental || kbuildsycoca5 --noincremental

Linux complete cleanup script

The cleanup script removes CrossSCP Flatpak, RPM, DEB installs, stale non-Flatpak desktop files, and optionally user config/cache/data.

# Preview only
bash scripts/uninstall-linux.sh --dry-run

# Remove packages and stale launchers
bash scripts/uninstall-linux.sh

# Also remove user config/cache/data
bash scripts/uninstall-linux.sh --remove-config

# Non-interactive cleanup
bash scripts/uninstall-linux.sh --yes --remove-config
