Clean-room Rust + Qt SFTP client

Fast dual-pane file transfer for modern desktops.

CrossSCP is a cross-platform desktop SFTP client designed for straightforward local-to-remote workflows: browse both sides, select files or folders, transfer recursively, and keep an eye on session activity.

Core features

CrossSCP focuses on the essentials of secure file transfer while keeping the interface familiar and productive.

⇄

Dual-pane transfers

Browse local and remote SFTP folders side-by-side, then upload or download selected files and directories.

🔐

Password and key auth

Connect with password authentication or SSH private keys, including keys discovered from your local SSH folder.

📁

Recursive folder operations

Transfer complete folders, create directories, delete files, and manage common local and remote file actions.

☑

Batch selection

Select multiple files or folders and run upload, download, or delete operations as a batch.

🧾

Session visibility

Review current-session queue entries and activity logs so you know what happened during a connection.

⚙

Open-source foundation

Built as a clean-room AGPL project with a Rust core and a thin Qt desktop interface.

macOS first-run visual guide

If you install the unsigned beta by downloading the app manually, macOS may require these extra approval steps. The terminal installer is still the easiest tester path.

Click Done

When macOS shows Move to Trash / Done, choose Done.

Open Settings

Open macOS System Settings from the Dock or Apple menu.

Privacy & Security

Select Privacy & Security in System Settings.

Open Anyway

Scroll to Security and click Open Anyway for CrossSCP.

Confirm

When prompted again, choose Open Anyway.
